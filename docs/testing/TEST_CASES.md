# 全功能验收用例基线

计划见../../plan.md。本轮案例状态初始为未执行；旧54项及demo截图仅作为既有基线，不计本轮实机PASS。

| ID | 优先级/阶段 | 前置与步骤 | 预期与证据 |
|---|---|---|---|
| ENV-01 | P0/T01 | 只读记录主机/雷电/ADB owner及host协议，读取list2与已注册串号 | owner前后不变；别名归属有证据，无重复算设备 |
| APK-01 | P0/T01 | 主机静态APK存在、SHA256、manifest/version/ABI/签名可得性；不执行guest查询 | 属性与未知项明确；不因文件名假定包名或已安装版本 |
| SAFE-01 | P0/T03 | 假服务/错误客户端测试guard；实机前固定host/port/绝对路径 | 不auto-start/kill/connect，服务不存在/版本异常明确拒绝 |
| SAFE-02 | P0/T03 | 假服务列出授权A及未授权B，测试发现和shell/write；超时派生进程夹具 | 不查询B详情、不向B写入；超时只结束自己客户端，原始状态保留 |
| SETUP-01 | P0/T03A | 用户确认空白新实例或指定独立编号；唯一serial、ABI/native bridge、首次安装、包版本与前台核验 | 不复制个人账号；给定APK安装效果有证据；不覆盖现有同包、不删除实例 |
| CON-01 | P0/T04 | 只对canonicalSerial读取属性、wm size、查询状态 | 全信息是同实例，离线/未授权不是Ready |
| IMG-01 | P0/T04 | 实机截图、PNG解析、保存、裁剪、取色 | 图像非空且真实尺寸正确；裁剪/颜色与相同坐标匹配 |
| NODE-01 | P0/T04 | 实机dump、树/矩形联动、属性、导出；选择节点不点击 | 节点与图对应，选择不向设备投递动作，内容私存 |
| SHELL-01 | P0/T04 | 只读白名单命令、坏命令、历史、取消/超时 | 输出可见且对应目标，失败不报成功，不堵后续 |
| APP-01 | P0/T04 | 应用读取、包名/版本筛选、核对输入APK | 真实结果与installed package一致 |
| APP-02 | P0/T05 | 批准后启动/停止目标应用，核对activity/PID与前后截图 | 实际前台/进程效果正确，不登录/发业务内容 |
| INPUT-01 | P0/T05 | 批准的安全页面Home/Back及tap/swipe，旋转/尺寸代次 | 落点/目标正确，旧代次拒绝，焦点变化能发现 |
| TEXT-01 | P0/T05 | 批准输入框中文/英文/空格/符号，雷电CLI与文本页分别登记 | 真正文本可读一致；501/缺agent记功能未满足而非PASS |
| FILE-01 | P1/T06 | 批准临时目录push/pull、取消、缺文件、无效路径 | SHA256一致、进度/失败清楚，删除仅本runId |
| SCRIPT-01 | P0/T06 | 合法/坏包、参数、运行、重复、取消、步骤失败 | 不重复，取消2秒内无新步骤，日志与状态一致 |
| API-01 | P0/T07 | health/目录、端口重复/冲突、坏JSON、错误method/Origin/ContentType | 分别核对普通/Automator envelope和错误码 |
| API-02 | P0/T07 | 27路由与雷电8动作逐条匹配真实前置/权限 | 实际效果核验，未支持与阻塞不混作通过 |
| UI-01 | P0/T02 | 12页实际导航、两尺寸、三视图、折叠、空态、长名称 | 内容不重叠、控件可达、高亮与页面一致 |
| UI-02 | P0/T02 | 当前/主控/勾选三概念，跨页输入/裁剪/参数保持 | 操作目标不因导航/过滤/隐藏页反向清选变化 |
| UI-03 | P0/T02 | cards/screens/list分别筛选B、空筛选、还原；全局清空 | 当前/主控保持，隐藏勾选被清，正确作用范围 |
| UI-04 | P1/T02 | 所有button/toggle/输入/selector：正常、忙、空/离线、坏值 | 真实控件清单逐项留结果，禁用符合能力/命令约束 |
| UI-05 | P1/T02 | 下拉/列表横纵滚、树展开、主控展开、扫描/目录窗、扩展底部 | 内容/按钮可达；打开扫描窗不自动执行扫描 |
| DATA-01 | P0/T02 | 独立配置保存/重启、损坏备份、并发绑定合并 | 不覆盖用户原数据，三方合并/语言/偏好一致 |
| FAIL-01 | P1/T08 | 只在独立fixture模拟超时/离线/坏响应，真实恢复需批准 | 失败可见，所有权清理，不误杀共享server或模拟器 |
| SOAK-01 | P1/T08 | 单实例30分钟/200查询/30截图/10节点读取 | 逐条耗时/错误/资源/服务owner，零崩溃/误投 |
| HOST-01 | P1/T08 | 有任务退出确认、取消退出、正常退出；demo错误启动 | UI/runtime资源回收且设备不退出，无残留GUI |
| RISK-01 | P2/T09 | 专用实例授权后安装卸载/清数据/重启/root/时区/恢复 | 无授权BLOCKED；有授权需目标/前后基线/恢复验证 |
| MULTI-01 | P2/T09 | 两个真实独立实例，尺寸不同、同步、代次/断连 | 不能使用同实例别名冒充双台；0重复/误投证据 |
| VIDEO-01 | P1/T09 | 提供可信scrcpy/agent后视频、输入、自有窗口恢复 | 真正动态画面/输入与PID所有权，不以截图墙代替 |

控件和路由子用例采用UI-04-页面-控件与API-02-路由命名，每项单列授权、预期、实际、证据及结果。所有功能点都必须有分类，不要求在当前个人账号里危险执行来凑覆盖率。
