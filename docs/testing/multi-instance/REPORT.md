## 发现及处理

跨实例LD写API被全局脚本忙态误挡：按唯一且实际核验的绑定serial收窄，未知/代次变更仍保守；真实A脚本Running/A409/B200/Home效果证明修复，仍不宣称跨进程事务锁。

SDK启动阶段list2状态2：本机原始输出证明过渡值，10列2仅视为未就绪，Ready只取1；不接受任意未知状态。测试脚本四数swipe、滑动后的旧坐标、过早/写死Home检查均为harness缺陷，失败保留，修复后短预检通过，不当生产串台。

最新完整回归72/72与独立复跑72/72；历史short smoke-round4 12条PASS/0FAIL、A5/B4数据轮，9条returns唯一对应设备nonce/SHA。29个HTTP请求含1个预期拒绝409，其它28成功；所有请求均proxy0，没有将它们冒充HT捕获。

首轮pressure-final-direct失败：B在高频force-stop后`am start -W`等待300秒超时，A随后取消；62次完整数据回传但只运行602秒，不能算15分钟双实例稳定。诊断未见ANR，B设置Splash/活动记录但无settings进程，根因未被证明为本机socket死锁。仅修改harness为正常主页/重新打开设置、实际前台和节点核验、共享45秒UI预算，不改生产启动契约、不无限重试。新增空框校验误将Android hint识别成文字，实际节点/截图证明后只允许确切控件与hint；最终输入全文校验不放宽。全部失败证据保留。

## 抓包限制与可行方案

HTTP Toolkit默认启动会使用共享ADB，本轮按进程环境隔离并核5037不变。其实际8000代理监听::，Public/Private防火墙又关闭，工具本身未发现免费官方loopback监听选项。已停止自有代理，没有擅自改防火墙、证书、VPN或Frida。

可选方案是由用户接受临时启用当前Public防火墙及限定HT端口的影响，记录原状态与自建规则，实际验证外部阻断/本机代理可用后采集，结束仅撤自建规则并恢复授权范围内状态；或在已有隔离环境做抓包。未经批准不实施。完整HAR需要Pro，免费读取可留实际events列表及代表正文，不能绕过订阅。

文件push/pull走ADB SYNC、APK安装走exec stream，不是HTTP；HT可分析经过代理的程序API与受控回传，不能据此宣称捕获这些二进制或APP自身TLS。App HTTPS还需要另行代理/证书范围与兼容验证。
