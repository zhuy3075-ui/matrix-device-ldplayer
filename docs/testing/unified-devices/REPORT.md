## 发现的问题与处理

1. 旧ADB白名单仅有两个测试串号，本机实例目录与设备墙独立；未建立其它实例绑定。现在完整本机目录和待接入区均可见，授权与在线状态分开计数。
2. 旧AutoConnect=false导致启动时不把已有快照同步界面。现在初始快照总会同步，但不自动扩权。
3. 旧截图刷新不是设备发现，且全局Busy会影响API写入。现在目录、状态与截图分开，有预算、轮转、关闭取消及独立防重入。
4. 仅中文输入核对LD身份不够。现在所有LD绑定的ADB操作，以及SDK和对应agent服务入口都有身份门禁；未确认串号不读guest；服务进程/实例会话变化不重放旧操作。
5. 仅更改settings不能更新冻结的Backend/中文回调/API绑定。接入前排空UI、脚本、传输、扫描和HTTP请求；保存前核对候选运行时，通过后切换，失败保留原授权。未在此次接入中的旧实例不顺带续授新身份。
6. 独立审查发现资源等待期间代次漂移，以及确认后在ADB等待循环中替换实例。先有负例，再冻结确认前与启动后快照；只有“未注册ADB”可重试，其它身份变化立即退出。
7. 新建目录唯一确认与配置提交是两步，后者失败会明确保留已创建索引，不删除或重复新建。配置提交成功不冒充实际CPU/RAM已生效。

## 验证与证据

- 完整离线测试：98/98；六项目Release构建0警告、0错误。包含新增顺序启动/取消/超时/身份漂移/创建歧义/冷态资源白名单，及host-only目录、所有guest门禁、epoch继承、确认主体和HTTP在途计数。
- 桌面demo：1440×900与1000×700，各12个内部页面、11个侧栏入口、3种设备视图、统一页内切换、中文、忙态/离线、取消确认及上下文保持通过。截图目视检查未见遮挡；demo不等同真实设备操作通过。
- 本机只读`list2`：23个实例，4个运行（0/1/2/3），19个关闭。相比用户截图数量已增加，以本次查询为准；本轮未新建或关闭这些实例。
- 本机授权配置CLI bootstrap：仅两个原授权独立实例Ready，LD和ADB发现错误均空，同时可见23个本机实例。未放开其它21个串号，没有操作原0 guest。
- 实际WPF接入验收：复制授权配置到隔离artifacts目录，初始仅加载2号；先取消接入并确认旧运行时/授权未变，再接入原已批准的1号。实际新运行时替换、两台已连接、截图可用，原2号连接保留；exit0，`admission-live/evidence/result.json`的passed=true。未提交launch或其它SDK写命令，不读其它guest。提交后用候选缓存更新界面，避免已提交却因最终刷新取消误报失败。
- 实机证据另经独立只读审查通过；取消仅覆盖入场前已取消token，不等于处理中取消或保存失败恢复。无启动/其它guest访问由调用路径审查支持，不是独立抓包计数。验收入口同时要求实际proof串号与复制配置原先批准的1号串号完全相同。
- 独立审查：预编译默认测试98/98、10.14秒、exit0；未发现新增可复现P0/P1阻断。结论仅限源码安全接线和离线测试，不能扩大为全量真实压力通过。
- 原始证据留在私有`artifacts/unified-devices/`：`build-verify.log`、`host-instances.json`、`authorized-bootstrap.json`、双尺寸JSON/控件状态/PNG；日志及授权不进入源码包。

## 未验证与风险

- 本轮未实跑全量23实例启动、真实空白创建/资源改写、复制、删除或全天稳定性；这些不能由fake-runner和demo绿色结果替代。
- 前轮VBox句柄增长仍列WATCH，不以本轮UI优化宣称已修复平台资源问题。
- 同一进程的统一UI门禁不能阻止用户同时操作雷电多开器/其它控制器；外部变化会尽量由快照和实际进程核验拒绝。没有实现跨控制器事务锁。
- 本轮未配置或实测可选phoneAgent；无LD绑定的独立agent仍沿用原显式授权边界。API认证升级不在本轮范围。
- 自动接入失败时保留详细日志和旧授权，不重启共享ADB、不放宽授权；用户检查实例状态后重新确认。实际资源配置需专用实例冷启动后回读，再考虑放宽保守资源预算。
