# 一键后台启动优化

日期：2026-10-15。前置版本：96f7387；不读取CODEBRAIN，不改既有授权范围。

## 目标与验收

- 删除底部独立待接入卡片区，将关闭、待连接及已连接实例合并显示；不向真实设备目录填入假串号。
- 用户点击启动即执行启动、真实端点核验、安卓与截图检查、保存接入；普通启动不再二次弹框，不强制切页。关闭、重启、创建配置仍保留必要确认。
- 启动所选与启动全部在原页面显示逐实例阶段、失败和取消；后台发现不启动、不扩权。
- 用户已明确要求隐藏雷电主窗口。官方文档及本机14.0.29.0帮助没有headless参数，采用核验PID/出生时刻/窗口所有者后的异步隐藏，不谎称真正无头、零闪现或节省GPU；只处理本次用户启动的非零实例。
- 可显示本程序隐藏的窗口，退出及失败可恢复；崩溃恢复记录不控制复用HWND或其它实例。0和99999、资源、共享ADB代次、API/脚本/传输排他门禁保留。

## 取舍

推荐：统一UI投影+原启动接入流水线+有恢复记录的原生窗口可见性控制。更简单：仅取消确认框，保留雷电主窗口；不能满足用户已确认的隐藏要求。拒绝试传未知headless参数、按标题隐藏所有窗口、写厂商私有配置或发现实例就自动启动。

失败模式：启动后窗口可能短暂显示；目标窗口线程无响应会使隐藏/显示校验超时；隐藏可能影响平台渲染；外部工具重启/改名造成身份变化立即拒绝。取消不关闭已启动实例，不吞隐藏失败。
