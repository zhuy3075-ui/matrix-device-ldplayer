- 默认打开“全部设备”的列表视图。关闭、启动中、待连接及已连接实例在同一个目录显示；取消底部独立待接入区域，保留卡片和屏幕视图，“高级管理”保留资源配置。
- 行内“启动”、工具栏“启动所选”和“一键启动全部”复用原串行启动与接入流水线。普通启动无第二次确认、不强制跳页；用户点击即授权本次目标进入真实身份、安卓启动与截图核验，成功才加入群控。后台发现不启动、不扩权。
- “后台启动”默认开启，只隐藏本次冷启动的非零独立实例。页内展示逐实例阶段与取消；行内或工具栏可显示自有隐藏窗口。失败、取消和正常退出会尝试恢复，不关闭模拟器。
- 未连接实例仅存在于UI投影，不伪造真实设备和串号。选择中含未连接实例时拒绝批量写入，不能回落到旧当前设备，也不能静默只处理在线子集。

## 官方支持与取舍

[雷电官方CLI说明](https://help.ldmnq.com/docs/LDPlayer-ming-ling-hang-kai-fa-zhe-shi-yong-shuo-ming)公开支持`launch --index/--name`；本机14.0.29.0无参数帮助及公开文档未提供headless、hidden、quiet或minimized启动参数。本次没有猜测或试传未知参数。

实现采用[微软ShowWindowAsync](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-showwindowasync)隐藏核验后的目标窗口，检查PID、出生时刻、安装目录、HWND所有者和随机窗口标记，先落盘恢复记录，再隐藏并核验可见性。恢复拒绝错身份或复用窗口，保留恢复失败记录。

这不是虚拟机真正无头模式：窗口出现到识别隐藏之间可能短暂闪现；不能承诺零闪窗、降低GPU/CPU占用，或任意应用在隐藏后持续渲染。仅取消确认框更简单，但不能满足用户已确认的隐藏主窗口要求；按标题隐藏全部窗口、写厂商私有配置及猜测无头参数均被拒绝。

## 发现与处理

| 问题 | 处理 |
|---|---|
| 两个目录分区导致关闭实例难找 | 合并UI投影与三视图，不改真实授权目录 |
| 普通启动多一步确认且跳页 | 点击直接执行，阶段/错误/取消留在原页面；危险动作确认保留 |
| 全选过程中Refresh导致集合枚举失效 | 对当前筛选结果先取快照再修改 |
| 选关闭实例却写旧当前设备/在线子集 | 统一跟踪未连接选择；按钮与执行入口双重拒绝 |
| 异步隐藏取消后可能晚到 | 失败清理等待隐藏任务，并对本轮目标无条件尝试Show，不以瞬时IsHidden跳过恢复 |
| 图标按钮被默认内边距压缩 | 复用现有IconButton样式；取消按钮清除多余内边距 |
| 历史连接成功阶段可能盖住断开状态 | 连接失效后不采用历史“已连接”阶段，新增demo回归断言 |
| 验收串号事后才核对、恢复失败可能残留PASS | Apply前检查冻结串号；本轮runId、先写未通过状态、恢复异常也最终落盘且不能通过 |
| 最后一次UI渲染可能早于数据绑定完成 | smoke等待ContextIdle/Render，验证可见卡片、子节点及尺寸后取图 |
