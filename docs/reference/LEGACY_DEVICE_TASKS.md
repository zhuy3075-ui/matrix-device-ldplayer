# 开发准备与后续任务

当前执行入口调整为 [雷电任务](codex/ldplayer-control/TASKS.md)，最新目标为原生窗口嵌入网格、双实例同步及控制 API。下表保留原实体设备研究的任务背景；不再把实体设备到货或自建 scrcpy 投屏作为当前窗口原型的前置条件。

更新日期：2026-10-14。以下为建议计划，未创建新产品工程。用户决定范围和风险接受；实现代理负责落实，独立 reviewer 负责核验。验收数值是本次整理提出的候选目标，不是实测成绩。

## 设备到货前可推进

- [ ] 将参考 PRD/spec/uispec 收敛成首版建设规格；原参考文档不覆盖或伪装成新规格。
- [ ] 盘点可用运行环境，锁定 ADB/scrcpy/uiautomator2 配对版本；不混用厂商组件。
- [ ] 准备非生产测试应用/数据、隔离条件、服务所有权规则和可恢复基线。
- [ ] 设计设备目录、会话状态、每设备顺序队列、API 校验、重复任务、超时与取消。
- [ ] 准备真实像素捕获与启动前采样；到货表包含 serial、连接拓扑、系统版本、分辨率和网络参数。

## 仍需硬件动态验证

投屏/输入实际效果、目标系统和私有 agent 兼容、驱动/授权、USB/供电/网络稳定、设备间串台与掉线恢复、多路解码渲染、真实容量和延迟。宣传中的系统/检测能力不能由桌面字段存在推定。

完成每一阶段后，在 PROJECT_STATUS 更新结果与限制，必要时新增开发测试记录。当前目录清理不意味着后续开发禁止测试或日志，而是旧研究中间产物不再混入新工程。
