# UI规格：清晰、轻盈的设备工作台

日期：2026-10-15。保留12页信息结构和列表模式，采用Apple HIG的清晰层级、简短标签、渐进展开和尺寸适应原则，不仿造苹果系统窗口或宣称官方认证。

## 参考与实现取舍

已阅读[Apple布局](https://developer.apple.com/design/human-interface-guidelines/layout)、[侧栏](https://developer.apple.com/design/human-interface-guidelines/sidebars)、[排版](https://developer.apple.com/design/human-interface-guidelines/typography)、[按钮](https://developer.apple.com/design/human-interface-guidelines/buttons)、[动效](https://developer.apple.com/design/human-interface-guidelines/motion)。

将其原则用于Windows原生控件：不下载受许可限制的SF Pro/SF Symbols，使用已有Segoe UI/中文无衬线与Segoe MDL2符号。低饱和蓝作动作强调，青绿/琥珀/珊瑚用于状态；大面积中性浅色，避免整屏蓝色、重渐变或装饰图形。

## 视觉token

- 画布接近#F5F5F7，内容白色，正文接近#1D1D1F，次级正文#626269；真实状态仍有文字/符号，不仅靠颜色。
- 标题20/正文13/次级11至12，固定层级不按视口宽度缩字体；字距为0。中文使用系统无衬线回退。
- 控件圆角6至8，重复监控卡片8；边线细、浮层阴影柔和。页面区块用留白/分隔，不把整页和每个子组都套浮动卡片，不套娃。
- 渐变只作为极轻的选中/材料层次，不作为内容背景噪声；图像仍是设备真实画面。
- 按钮保留悬停/按下/禁用/焦点，100至160ms轻量淡入/颜色过渡；系统减少动画时关闭非必要动效。

## 响应式

| 窗口逻辑宽度 | 导航与主体 |
|---|---|
| 1100及以上 | 轻量侧栏，内容与检查器双栏，主要动作至多2至3个同组 |
| 700至1099 | 侧栏自动收敛，次要工具入菜单，双栏按内容阈值纵排 |
| 低于700 | 可访问的导航抽屉/紧凑导航入口，目标选择顶置，表单单列，检查器/主控可展开并返回列表；关键动作始终可达 |

手机尺寸验收390×844和390×640，平板768×1024。不得只把MinWidth调小；节点、取色、应用、设置和监控的固定宽栏都要重排，弹窗尺寸受Owner和工作区约束。数据表有意横向滚动时标题、目标、选择和主要动作不得被遮挡。

最低尺寸的窗口XAML、启动smoke参数、设置校验及持久化Normalize采用同一约定；实际尺寸必须断言，不接受390请求被悄悄Clamp到1000的伪适配。字体放大与真实DPI各自留证，不混作一个用例。

## 每页重点

设备：一份列表、一套勾选目标、主控与投屏目标一致。监控：画面优先，资源是次级信息，暂停/切换状态明确。界面检查/截屏：画面与检查器关系清楚，窄屏分段可返回。终端/文本：输入和结果/发送对象清楚，不塞介绍文案。应用/文件/自动化：目标、计划、进度、结果相邻但不混淆。接口：服务拥有状态与请求结果分开。工具/设置：分组表单和低频展开，不混入其他页重复业务入口。

## UI验收

每页在6种尺寸运行真实控件路径并目视截图；验证导航、焦点、可滚动边界、长中文/串号、空/加载/成功/失败/禁用、150%字形布局。普通文字对比至少4.5:1，大字和必要非文本边界至少3:1；紧凑布局触控命中区域至少44逻辑单位，图标本身可更小。图标需中文可访问名称、可见焦点，验证Tab/Enter/Escape、菜单返回及无焦点陷阱。一个页面截图或仅控件数量不能证明整体视觉完成；动画、颜色对比、字体放大与真实DPI分别记录。
