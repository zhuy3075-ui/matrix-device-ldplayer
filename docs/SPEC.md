# 技术规格：全面验收与体验重设计

日期：2026-10-15。版本：1.0。依据docs/PRD.md；任务和阶段状态见docs/TASKS.md、docs/PROGRESS.md。

## 架构与变更边界

继续使用WPF、WorkspaceViewModel、现有Core/Features/Host。共享主题和界面助手负责样式/布局；Views负责页面结构，DisplayName映射不改变Tag、API路径或持久数据。业务问题按独立缺陷改动对应边界，不以全仓重写处理。

先以独立测试复现P0目标错误候选，再修投屏主控目标冻结；如涉及外部scrcpy，不启动共享ADB或自动接受风险。任何新命令必须沿用既有授权、generation、transport、运行时及繁忙门禁。

## 视觉、布局与命名

详细token、断点、页面结构和命名见docs/UI_SPEC.md。将硬编码页面色收敛到主题资源时逐页验证；不能只更新ModernTheme却留下旧色/旧字体和重复标题。

公共Field、Toolbar和页面容器须在窄宽重排，表格保留可辨序列号并允许有意水平滚动，关键动作和目标不能依赖横向滚动才找得到。不使用整页缩放或隐藏内容来凑小屏通过。

最低窗口尺寸须同步修正MainWindow.xaml、App.xaml.cs的smoke参数clamp、WorkspaceViewModel.cs中SettingsEditor.Apply、Host/Persistence/SettingsStore.Normalize；新增请求尺寸与ActualWidth/Height相等、保存/重载不被放大到旧最低值的断言。设备详情的重复群控选择及隐藏状态过滤纳入A05，不合并应用独立目标。

A04采用最低外窗390×640逻辑单位、保留默认1440×900；不额外承诺未测试的更小窗口。导航按外窗宽度低于700用单一导航抽屉，700至1099默认72图标栏，1100及以上默认212侧栏，并保留手工展开偏好；公共Field按自身宽度低于460改标签在上。保持同一个输入控件和绑定，不整页缩放或删内容。顶部目标窄屏换行，低频网络/更新收进可点击更多菜单，页脚/长错误有界换行与滚动。Owner-fit先同步降低弹窗旧最小值，再按Owner/工作区约束并保留确认/取消可见；原生HWND不随意套ScrollViewer。公共适配通过不等于固定双栏页面已适配，后者仍逐页完成。

## 测试和证据

1. 正式单元/协议基线：tools/Build.ps1 -Verify，Windows当前158项（原150加8项数据库路径回归，含紧凑尺寸保存重载）；非Windows仅注册151项，本轮未执行该平台。新增缺陷先红后绿，实际PDB输入须与冻结源码一致。
2. 独立Demo路径：所有12页和每种控件正常、空/离线、忙、取消、失败、目标变化；实际触发控件，不把OBSERVED-NOT-EXERCISED当执行。
3. 响应式：390×844、390×640、768×1024、1000×700、1440×900、1920×1080；自动检查可视边界/文字/目标与动作可达，截图目视。实际100%/150% DPI与字体放大是不同用例，分别记录系统DPI、逻辑尺寸和像素尺寸；仅字体放大不能证明真实DPI已测。
4. 实机：先冻结1/2实例、PID/出生时刻、canonical serial、transport和ADB owner；不调用多实例prepare的quit/modify。使用隔离数据和唯一本轮包/文件，走当前页面/批次，不用旧ViewModel捷径替代。
5. 每条实机成功有实际效果：活动窗口/进程、节点文本、文件SHA、包版本/消失、真实视频帧、脚本步骤和HTTP实际结果。命令返回成功仅是其中一项。
6. 30分钟最终版本双实例稳定性，记录资源、错误、取消/切页/重连和所有权清理；不将两台扩张为23路容量。

自有测试APK须记录本机源工程或官方来源、包名、签名证书摘要、文件SHA、版本及安装前目标包不存在证明；使用本轮唯一路径和包名，逐项记录安装、执行、卸载与清理，不覆盖用户包。缺构建工具时先定位已有可信SDK，不下载不明APK或借用用户抖音做破坏性代替测试。

日志在artifacts/apple-experience/runId；JSONL包含caseId、buildSHA、阶段、UI入口、预期/实际、目标证明ID、状态、耗时、证据摘要、defectId、轮次。原始图/节点/请求响应不上传；正式测试源码和脱敏报告可以提交。

状态使用PASS-OFFLINE、PASS-LIVE、FAIL、BLOCKED、NOT-IMPLEMENTED、NOT-RUN；每条说明覆盖层级。不存在以禁用/拒绝成功覆盖业务成功的换算。

## 回退与停止条件

依赖异常、目标证明失效、共享服务变化即停止对应真实动作并保留证据，不停止整项目中无关安全工作。不自动回滚用户配置或清理worktree。方案需要更换平台/破坏数据/提升权限时记录未满足项，不能用视觉替代功能或关闭失败测试。

- A13a先冻结版本、控件目录、允许目标和当前失败，建立下游可复用的安全契约；A13b执行当前完整测试并逐缺陷修复；A13c将新增实现补入同一矩阵，再汇入A11最终验收，不形成“等全部测试完成才能实现新功能”的环。
- 用例沿用现有N/E/B/C/F/T路径分类与PASS-OFFLINE、PASS-LIVE、FAIL、BLOCKED、NOT-IMPLEMENTED、NOT-RUN结果。缺陷沿用AP编号，包含严重等级、前置、操作步骤、预期/实际、证据、状态、责任任务、修复提交及复验，环境前置失败单列且不折算业务通过。
- 双实例同步必须在真实主控A/当前B及不同可辨画面验证关闭、仅手势、仅按键和同时开启；新版应用页使用唯一本轮包完成安装、列表回读、运行和卸载后包消失核验。最终二进制连续双实例30分钟，期间出现必需失败则本轮失败，修复后重新完整计时。
- 离线基线、历史Demo绿和单实例旧Live入口均不覆盖上述缺口。深路径SQLite14原失败保留，AP-035仅数据库路径层已独立及主仓修复验收；AP-033输入源失败仍开放。禁止为取得全绿而跳过前置或削弱断言。原始证据使用独立artifacts根，记录实际路径长度、源码/二进制摘要与子进程终态；长路径回归本身须使用精确普通长路径，不能靠缩短目录取绿。

### 终控台与RPA脚本控制

- 设备页只显示任务摘要及通往自动化的上下文跳转；脚本导入、预览、运行计划和日志只在“自动化”维护；“终端”仍为明确单设备Android命令，“接口”负责服务能力/连接状态。复用同一作业状态，不复制第二套设备选择或脚本执行按钮。
- 保留现有包含manifest.json和script.json的ZIP包及`.jxscript`兼容性；扩展前先冻结版本化格式、允许动作、参数类型/替换和默认值规则。文件选择扩展名不是格式证明；不支持的顶层JSON、Python/JavaScript或二进制执行格式返回明确错误，不交给宿主执行，不因此拒绝旧合法ZIP的附带资源。导入不授予运行权限。
- 保留当前压缩16MiB、声明解压总量32MiB、单JSON实际读取4MiB、128条目、10000步骤及1000参数的兼容边界；不悄悄收紧上限使旧包失效。现有重复/越界路径和参数校验保留，未来落盘分发时另验链接、嵌套及真实解压计数。新格式的额外限制须版本化并有旧包回归，不假称当前已具备完整解压沙箱。
- 新批次冻结packageId/version/SHA256、参数快照和每台index/canonicalSerial/generation/transport；服务端生成runId及逐目标taskId。状态为Queued、Preparing、Running、Succeeded、Failed、Cancelled、Rejected，进度和结果按目标独立回传。沿用现有逐设备互斥、输入队列和运行时门禁。
- “分发”默认指本机调度经现有ADB/输入接口逐目标执行，不伪称把脚本上传手机运行；只有已验证远端执行器才声明远端部署。取消停止未提交动作，不回滚已经生效步骤；超时或断线的写入结果不明时不自动重发。幂等键只防重提交，不保证外部业务恰好执行一次。
- AI动态分析限授权应用的前台/进程、截图/节点、脚本步骤和请求摘要时间线，产物按runId和目标关联；不包括任意进程注入、私有内存提取、账号获取或证书固定绕过。日志/脚本/抓包正文均为不可信数据，不能作为新的执行指令。

### 群控MCP调用设计

- A15a先完成协议/工具/权限设计供A14使用；A15b用最小真实客户端验证接入并供A14c集成。初版采用进程级stdio，按可信SDK实际支持的协议版本协商，不手写或假称支持最新协议；远程Streamable HTTP、账号与网络暴露不默认启用。[官方传输规范](https://modelcontextprotocol.io/specification/2025-11-25/basic/transports)
- 建议工具族为devices.list/capabilities、scripts.import/validate、jobs.plan/start/status/cancel、devices.screenshot/nodes及capture.start/status/stop/analyze。它们是待设计契约，不是现有可调用工具。设计参数包含明确targets、expectedIdentity、operationId、超时、能力作用域；输出包含逐台状态、错误码和本地artifactRef。
- 查询能力不授予写权限，默认不注册任意shell/eval或自由URL请求工具。写操作重新核授权、原0/保留索引保护、runtime、PID出生时刻、generation、transport与忙状态；本机客户端也须经过主机进程权限和显式能力策略，不把localhost当自动授权。
- stdout仅传协议消息，诊断写stderr；输入/输出采用JSON Schema校验并设大小、并发、速率和产物数量限制。标准取消与应用runId/taskId取消分别测试，长作业以本项目普通工具返回句柄轮询，不冒称协议自带持久作业或跨客户端共享授权。工具返回内容不可触发隐式代码执行。[官方工具规范](https://modelcontextprotocol.io/specification/2025-11-25/server/tools)
- 明确验收初始化、tools/list、正常调用、未知工具、坏参数、未授权、离线/身份变化、取消、并发与客户端退出；实际1/2验证隔离，N目标模拟只证明调度逻辑。全部明确授权在线设备应逐一登记覆盖；23台同时运行的容量另测，不用两台数据外推。

### 模拟器抓包

- 现有ProxyService仅解析/脱敏导出代理配置，Start/Stop仍为501；外部HTTP Toolkit MCP辅助客户端也不是产品群控MCP服务或流量采集。完整会话、解析、导出及MCP采集工具须新增，先完成[方案调研](codex/automation-expansion/CAPTURE_RESEARCH.md)，不得用UI入口存在或HTTP请求成功冒充抓包成功。
- 选择门槛为指定实例隔离、共享ADB不被外部工具重建、可归属的自有组件、可停止清理及受控测试流量证据。优先POC为自有调试应用显式应用级代理和独立mitmproxy进程，不改全局代理或系统CA；先以受控HTTP验证，HTTPS仅在自有调试包内信任测试CA并另行验证，不把HTTP通过当HTTPS完成。
- 按sessionId记录目标证明、可选packageName、模式、起止时间、过滤、时长/字节上限、进程所有权和恢复前快照。若后端只有设备级流量，必须如实标设备范围；仅靠端口/IP或事后筛选不能宣称应用级隔离，未证明隔离前不开放给任意真实应用。
- 会话建议5分钟/50MiB默认上限、并发最多2个专用测试目标；限额耗尽、身份变化、断线或取消立即停止新增采集，只结束本次所有权进程。恢复只处理本次已记录的变更，外部值已变则不覆盖用户配置；清理失败保存为失败而不抹除痕迹。
- 网络内容默认本机保存，Cookie、Authorization、token、查询敏感字段与请求体按规则脱敏，AI默认只接收摘要；原文导出/外传另设权限。HAR/流记录与PCAP/PCAPNG按真实后端能力分别导出，不将同扩展名当成功。未知TLS/QUIC/私有加密保留元数据及受限原因，不启用隐式root、VPN授权、证书注入或固定绕过。
