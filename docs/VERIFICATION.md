# 验证还原结果

当前实机验收记录见[独立实例报告](testing/REPORT.md)，接口逐项证据见[接口矩阵](testing/API_MATRIX.md)。以下未完成的多实例、agent、scrcpy、root与容量步骤仍是后续验收，不得当本轮已通过。

## 可重复离线验证

运行 `tools/Build.ps1 -Verify`。每条测试打印PASS/FAIL和最终计数，非零退出即失败。覆盖坐标/编码、PNG、逐设备队列/取消、离线重连代次、同步源排除、节点AND/前序/WaitAny、节点选择不tap、脚本格式/坏包/取消/失败日志、配置备份与三方合并、SQLite重载、手机DTO/坏响应、两种实际HTTP监听/坏JSON/端口冲突、文件字节隔离、日志flush。使用两个明确标识的demo设备，不调用真实ADB。

运行桌面 `--smoke --screenshot ABSOLUTE_PATH`；该模式自动demo，渲染主窗与所有标签页，再退出。检查截图有内容、按钮文字不溢出、设备身份始终可见，截图/树选择联动，错误和忙状态独立。

源码交付验证：运行 `tools/New-SourcePackage.ps1`，按 `SOURCE_MANIFEST.json` 对全部文件重新计算SHA-256；源码包内含11份原参考文档，可和用户原目录逐字节比较。

## 专用设备验收

1. 先正常启动雷电的现有ADB服务，显式配置授权serial与唯一LD索引绑定，记录服务PID/出生时刻、transport、型号/Android/分辨率/拓扑。程序不执行adb.exe、不启动/停止服务；无授权不查询guest，离线/未授权不得显示Ready。手动网段扫描需区分TCP发现与ADB连接计数。
2. 单台验证截图、节点树、Shell、tap/swipe/Home/Back、应用读取/安装、文件双向字节校验、文本；持续30分钟记录错误与资源。安装/清数据/卸载仅用户选定测试应用。
3. 两台不同尺寸设备执行100组点击/滑动/按键；切主控、旋转、取消、掉线/重连，检查零串台、零重复、无旧代次投递。ADB模式验收完成手势，不能称逐MOVE实时同步。
4. 在API面板启动普通网关、两设备端口和Automator，逐条请求比较reference/API.md；普通DurationMs与Automatorsteps/stepMs分别验证。agent只绑定其明确serial，核验版本和真实HTTP结果。
5. 导入合法/坏脚本包；10次停止两秒内不再执行新步骤；重复运行只产生一个任务；离线取消；步骤失败对应Failed状态和设备日志。
6. 配置外部scrcpy路径，检查真实动态画面、输入、100%/125%/150% DPI、附着失败恢复、正常关闭恢复。原生窗口PID/启动时间不匹配必须拒绝。不得销毁非自有HWND或清共享ADB server。
7. root/代理/备份仅在用户接受影响范围后对专用测试数据执行；验证系统实际效果、失败原因和恢复基线。离线归档通过不证明恢复安全或ROM兼容。
8. 2→5→10→20台固定分辨率/FPS/码率阶梯测试；每档记录CPU/GPU/内存/带宽、输入延迟、连接率/恢复。阈值由硬件与业务决定，不把mock行数作为容量证据。

本轮已测试批准的独立雷电实例和提供APK；真实agent、scrcpy、root/ROM、多实例与容量仍未测试。请结合 `ASSUMPTIONS.md` 对未知项补证，不把代码存在或返回“命令已发送”作为验收。

## 雷电接口验收

新增测试默认只用内存实例和本工程子进程，验证7/10列兼容、中文GBK、参数边界、输出上限、超时/取消、代次、确认与本机HTTP限制。桌面smoke只验简体中文和demo实例，不触真实模拟器。

用户确认只读范围后，可运行 Tests.dll `--ldplayer-live-query 'E:\leidian\LDPlayer14\ldconsole.exe'`，经本机HTTP查询真实list2后退出，不启动ADB客户端。使用当前共享ADB时，先明确授权串号、服务版本与进程代次；禁用自动connect/kill-server，不使用公式自动绑定。

动态验收应由用户指定专用实例和测试APK：逐项启动/退出/重启，实际应用运行与安装，聚焦测试框后的中文输入，主页/返回/音量，逐次重新GET读取generation；动作前确认范围，核验实际界面及guest结果。已接收但未验证必须保持 `verified:false`。随后验证截图、节点、文件哈希和不同尺寸两实例输入，排除同实例串号别名重复。整机恢复、删除、root、身份和网络变更不属于本轮接口。
