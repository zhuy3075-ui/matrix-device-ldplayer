目标：按用户两张图片的浅色蓝白工具界面重做WPF外壳；采用第二张的侧栏与群控工作区，以及第一张的设备摘要卡片。保留矩阵设备品牌、简体中文、雷电接口和现有12页的功能。

范围：左侧可折叠导航、顶部统一筛选/搜索/发现、持续可见的当前设备/主控/目标上下文、卡片/屏幕/列表三视图、基础控件主题、错误/忙态/空目录反馈。截图中的账号、授权数量、到期日期、云市场、品牌不是需求，不制造对应业务能力。

推荐：保留同一个ViewModel和页面实例，仅换WPF外壳、主题和墙页展示。更简单方案仅调整旧页签颜色，不能满足侧栏和三视图。拒绝引入Web前端/新协议重写：增加部署和测试成本，且没有新业务需求。

P0：保留全部12页和命令约束、选中/当前/主控概念、跨页输入与裁剪状态；验证真实导航入口和既有54项离线测试。

P0：布局、主题和三视图；验证1440×900及1000×700全部页面非空，侧栏可滚动/折叠，长名称/空目录不会重叠，卡片调试和主控操作仍用原命令。

P1：独立review、文档/截图与新源码包；保留旧源码包，不执行真实ADB、雷电命令、扫描或设备输入。
