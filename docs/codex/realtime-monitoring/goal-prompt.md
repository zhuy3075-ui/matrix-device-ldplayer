# 后续实施任务草稿：实时监控

本文件保留历史执行草稿。用户已授权实施及仅专用实例1/2验证，实际状态以REPORT和HANDOFF为准；不创建或启动goal、自动化或无人值守loop。

## 目标

依据requirements.md和plan.md，在现有.NET10/WPF工程增加画面优先的只读“实时监控”页；每张可见、明确授权且已运行的卡片无需选中或放大就能连续播放视频，并显示宿主CPU/RAM及15分钟趋势。单击看详情，显式打开对应已运行窗口供人工操作。仅专用1/2测试已获确认；扩大范围或改用外部ADB仍须另行确认。

## 范围

包含：独立监看选择、身份绑定采样、逐卡连续视频、有界最新帧缓冲、可见性起流/恢复、真实接收帧统计、陈旧/失败/暂停状态、CPU/RAM口径、事件与趋势、原生窗口显示入口、节点页首次自动加载。PNG仅作为明确标注的备用，不计实时视频验收。

不包含：未经容量验证默认23路全开、GPU/网络/APP FPS推算、自动重启或删除实例、原实例0操作、默认录屏/上传、账号/支付/权限操作、未获风险放行即启用外部scrcpy。监看视频默认无控制、无音频、无剪贴板同步。

## 约束

保持现有授权、SDK/ADB代次与进程身份门禁，不按串号公式授信。监控不得改变群控目标、主控、当前设备和节点树；明确点击进入节点调试除外。优先复用现有模块，改动与任务直接相关，不回滚用户工作。

## 验收

用户无需点击或放大，所有可见合资格卡片均能同时连续显示页面变化；先用2台再4台经批准的专用实例运行可识别动画/计时，记录独立帧序列/延迟和画面证据。隐藏雷电主窗口后也需验证视频持续更新。首次/失败/断开不能伪装0或绿色实时，静态页不误判卡死。单击/双击无意外guest输入和生命周期动作，重启后不续接旧数据；脚本运行时监看不破坏任务。

运行构建与默认离线测试、三尺寸UI检查、自有窗口测试；经批准的专用实例保存真实截图、采样耗时、失败/跳过、监控自身CPU/RAM、操作延迟证据。先2台再4台，更多并发另行批准，不能虚称23台达标。由独立verifier检查范围、代码和实际证据。

## 停止条件

需安装新组件、扩大guest授权、启动/关闭实例、改变共享ADB、接受投屏风险、保存连续画面、上传或改变目标性能承诺时，说明风险并请求用户决定。不可为通过而禁用检查或填入假指标。

## 最终报告

报告确切文件、行为变更、验证结果/证据、未验证项、剩余风险与设计偏差；用户批准仓库/分支/范围后再提交推送，不自行合并、发布或部署。
