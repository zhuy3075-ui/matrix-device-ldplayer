# 设备操作入口去重

日期：2026-10-15。状态：实现、隔离回归、整合及独立复核通过，新版已重新打开。只使用仓库上下文，不读取CODEBRAIN。

后续变更：设备管理已收敛为列表，独立实例下拉删除，主控从列表行“控制”打开；本报告保留上轮历史证据，当前入口及验证见[列表控制台精简](../list-console/REPORT.md)。

## 目标与范围

用户指出设备管理的整块实例快捷操作，与新应用管理及文本输入重复。根因是模块合并时保留了旧表单，没有统一功能归属。

删除整个旧快捷区及仅供它使用的字段和门控参数，不隐藏保留第二套表单。应用安装、卸载、启停归应用管理；文字归文本输入。主页、返回已有主控面板，只将原本独有的音量加减迁入同一按键区。仅默认折叠虽然更小，却保留重复入口，不采用；删除Core/HTTP SDK会破坏接口和脚本工作流，拒绝。

不更改真实设备、模拟器配置、ADB或APP数据，不改Core/Host/API。文件上传后安装、脚本和接口调试属于独立工作流，保留。

## 页面与组件

| 页面 | 改动与保留能力 |
|---|---|
| 设备管理 | LdPlayerView移除整个实例快捷操作Expander、应用包名/文字输入和旧应用/按键按钮；删除失效字段和专属参数。独立实例下拉及启动、接入、新建、配置、关闭、重启保留 |
| 应用管理 | 沿用既有独立目标勾选、应用列表、安装/卸载、更多中的启动/停止；无第二套应用表单 |
| 文本输入 | 沿用TextInput/TextCommand、群控或当前设备目标，以及AdbDeviceBackend.TextAsync至已授权LD绑定的中文转发链路 |
| 设备管理的屏幕视图/主控面板 | 已有主页、返回、任务保留，增加34像素音量图标和中文工具提示/无障碍名称，复用KeyAsync(24/25)及CanControlMainInput |

音量遵循主控和键盘同步规则，不再是旧快捷区的独立单实例指令。独立LD索引不暗中映射到应用勾选、群控选择或主控。原0/99999、繁忙、进程状态、确认取消、代次和身份门禁不变。
