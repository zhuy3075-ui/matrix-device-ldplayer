# 正式产品移除演示与 Mock 数据

日期：2026-10-22。承接用户“正式发布仓库”定位，按[本轮计划](PLAN.md)清理当前正式源码、构建入口、演示策略和界面截图。不重写 Git 历史、不删除本机用户数据、不恢复已暂停的实机与长期测试。

## 实施范围

- 两个数据生成器由生产 Core 移至 `tests/MatrixDevice.TestSupport/`；默认编译不包含其类型。Host 在创建目录、数据库、日志或后端之前拒绝 `demo:true`，不回退到假设备。
- 桌面验收 partial、测试启动器以及主窗口/内存提示中的内联验收移至 `tests/MatrixDevice.Desktop.Support/`；原断言保留。正式 App 仅接受真实配置路径和打开监控等正常参数，拒绝 Demo、smoke、verify、probe 及未知/重复/缺值参数，失败返回非零且不创建工作区。
- 生产 CLI 移除演示参数及虚拟 `--ldplayer-list`；原真实实例、ADB、输入、应用和 API 的身份/权限守卫未放宽。演示专用钩子仅在测试支撑编译条件下存在。
- 仅支持演示的 MCP 工程和策略移至 `tests/`。默认解方案只构建五个产品工程，没有冒充真实 MCP 或移除现有正式 HTTP 能力。
- `tools/Test.ps1` 先验证默认产品，再显式编译测试支撑。`EnableTestSupport=true` 缺少隔离 artifacts 输出时构建拒绝，测试输出使用新目录，不写默认产品 bin/obj。测试方案显式列出依赖项目，避免父解方案未列出引用工程导致 Release/Debug 混用。
- 删除 66 张旧演示/历史 PNG，以及包含旧演示生成器的源码拼接副本和两个过期清单。默认源码归档不含 `tests/`，完整开发归档需显式 `-IncludeTests`；生成的三个清单不再跟踪上传。
- 首页 7 张图替换为默认正式构建的真实空状态，不制造设备、应用、节点、视频、资源或脚本任务。独立工具只停止自有窗口的两个读取定时器并渲染现有页面，不读取用户配置、不调用设备。来源、尺寸与摘要见[截图说明](../../images/README.md)。

测试夹具仍保留在仓库 `tests/`，这是回归验证所需的人工数据，不进入正式产品或默认源码包；没有声称整个 Git 历史、旧分支或所有测试字符串均已抹除。用户脚本格式模板不是设备种子，保留且不自动导入。
