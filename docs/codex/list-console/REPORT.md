# 列表设备控制台精简

日期：2026-10-15。状态：实现、主仓构建、独立正式测试及三尺寸完整Demo验收通过，新版已打开。仅使用仓库上下文，不访问CODEBRAIN。

## 目标和事实

用户要求删除“全部分组”、设备管理仅保留列表，审查重复入口并改善难以理解的同步控件，不再提问。按截图保守解释为删除分组筛选和界面入口，不删除已有元数据或模拟器。

旧页面同时使用列表勾选、实例下拉、当前高亮三种目标。“启动并连接”操作单一下拉目标；“接入已运行实例”无视该目标，处理所有已运行未连接实例；二者和启动所选/全部最终进入同一ConnectLdInstancesAsync。同步鼠标只复制内嵌主控画面的点击滑动，不是操作系统全局监听；同步键盘只是程序内按键，不是雷电窗口的物理键盘镜像。无画面的列表保留这些开关会误导。

## 推荐决策

- 设备管理固定单一列表，移除卡片、屏幕切换和屏数控件。实时多画面仍使用独立“实时监控”，不删除视频能力。
- 删除所有分组筛选控件及GroupFilter/Groups路径，保留原元数据且不执行数据迁移。状态筛选保留在设备列表，设备详情不额外放置筛选控件；相关隐藏目标保护改用状态筛选验证。
- 删除独立实例下拉、“启动并连接”和“接入已运行实例”。启动所选、全部和行内启动统一自动判断冷启动/仅连接。配置、关闭、重启只允许列表恰好勾选一个有效实例；不回退当前高亮或CurrentDevice。
- 常用启动/新建保留直达，低频配置、关闭、重启、旧隐藏窗口恢复放“更多操作”。取消启动仅任务进行时显示。
- 全选/清空合并为表头三态复选框，取消勾选绝不删除设备或数据；保留显式选择和目标计数。
- 连接行以“控制”打开列表旁主控面板，面板中使用“同步点击滑动”“同步按键”复选框及精确提示。主页/返回/任务/音量/投屏保留。关闭面板回归全宽列表；默认不占列表宽度。
- 列表没有自动截图开关，也不后台轮转截取全部设备。仅主控面板可见且窗口激活时自动刷新主控；多设备实时画面仍归实时监控。

更小方案是仅隐藏切换/旧按钮，但会留下失效筛选和不可达主控，拒绝。把主控直接删除更简单，但丢失上轮已保留按键和投屏，拒绝。不开新模块、不改Core/Host/API、身份授权、内存确认策略或真实模拟器。

### 最小方案

独立源码盘点及实际基线复验发现两处仍易误读：实例“更多操作”与顶部“更多”近似，启动提示没有说明状态筛选隐藏的目标。推荐只改名称和提示，不改命令目标或新增确认：

- 实例菜单改为“实例操作”，保留资源配置、关闭、重启及旧窗口恢复，新增稳定Name `InstanceActions`；顶部更多仍为网络连接/立即更新目录。
- “启动所选”明确包括筛选隐藏的已勾选实例；“一键启动全部”明确操作全部可接入未连接实例，不受状态筛选限制。都说明已运行仅连接、不重复启动、排除受保护实例及成功核验后加入群控。
- 禁用按钮设置ShowOnDisabled，继续沿用现有360像素上限与自动换行的提示样式，不改全局主题。
- 图三已有收敛保持：三态表头统一全选/取消，两个同步选项只在主控面板，自动截图无列表开关。同步步骤为勾选其他目标、打开主设备“控制”、按需启用点击滑动或按键同步、在程序内主控操作；不监听雷电窗口的全局键鼠。实时多画面仍使用“监控”。

更简单方案是只在答复解释，但后续使用仍会遇到相同标签歧义，未选。删除“一键启动全部”或把两种同步合成一个开关会失去已要求的独立操作范围，拒绝。失败模式是用户忽略提示仍误以为“全部”只指筛选结果；本次没有扩大目标集合，日常优先使用“启动所选”，普通启动不重新增加弹窗。
